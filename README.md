# Ejercicio Práctico: Colecciones de Datos en Python

Este repositorio contiene la solución a la tarea práctica sobre el uso de estructuras de datos (listas, conjuntos y diccionarios) en Python.

## 📋 Descripción del problema
El programa implementa un **Sistema de Gestión de Contactos** que utiliza un **diccionario** como colección principal para almacenar y relacionar los nombres de las personas con sus números telefónicos.

## ⚙️ Funcionalidades del programa
- **Agregar datos:** Permite registrar nuevos contactos con su respectivo teléfono.
- **Mostrar datos:** Muestra en pantalla la lista completa de contactos registrados de forma organizada.
- **Buscar datos:** Realiza la búsqueda de un contacto específico por su nombre.
- **Eliminar datos:** Permite remover contactos existentes de la lista.

1. Asegúrate de tener Python instalado en tu equipo.
2. Descarga o clona este repositorio.
3. Ejecuta el archivo desde la consola con el comando:
   ```bash
   python contactos.py
